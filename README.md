# moka

Repositorio de práctica para aprender y experimentar con Git y GitHub. No contiene una aplicación funcional.

## Contenido

- `app.js`: script con `console.log` de prueba.
- `hola.txt`: líneas de prueba acumuladas a lo largo de distintos commits.
- `created_in_master`: nota creada directamente en GitHub sobre la rama `master`.
- `me`: archivo de prueba.

## Qué se practicó aquí

- Commits, ramas (`master`, `testing`) y merges
- Resolución de conflictos
- `git stash` y `git reset HEAD^`
- Conexión por SSH
- Edición desde github.dev / VS Code
